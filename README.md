# NerdStop Frontend (In Progress)

⚠️ **Project Status**  
This frontend application is currently in development and is being built to consume the NerdStop backend REST API.

The focus at this stage is on UI structure, routing, and frontend–backend integration.

---

## Overview

This repository contains the frontend of **NerdStop**, a full-stack e-commerce project for gaming and geek products.

The goal of this frontend is to provide a clean, responsive user interface while integrating with a custom-built backend API.

---

## Tech Stack

- React
- Vite
- Tailwind CSS

---

## Current Focus

- Application layout and component structure
- Client-side routing
- API integration with the backend
- Reusable UI components

---


## Notes

This project is a work in progress and will continue evolving alongside the backend as new features are implemented.
